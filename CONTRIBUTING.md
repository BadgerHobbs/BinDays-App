# Contributing to BinDays-App

Thank you for your interest in contributing to the BinDays-App.

## Project Structure

The BinDays project is split into three repositories:

- **[BinDays-API](https://github.com/BadgerHobbs/BinDays-API):** The back-end service that contains the logic for scraping council websites.
- **[BinDays-Client](https://github.com/BadgerHobbs/BinDays-Client):** A Dart library that communicates with the API.
- **[BinDays-App](https://github.com/BadgerHobbs/BinDays-App):** (This repository) The Flutter mobile application that uses the Client.

If your issue is with the mobile app, you are in the right place. For API or client issues, please visit the respective repository.

## Reporting Issues

If you've found a bug, have a feature request, or are experiencing a crash, please [**create an issue**](https://github.com/BadgerHobbs/BinDays-App/issues) in this repository.

Please provide as much detail as possible, including:

- Device (e.g., Pixel 8, iPhone 15)
- Operating System Version (e.g., Android 14, iOS 17)
- Steps to reproduce the issue
- Screenshots or screen recordings, if applicable

## Development

If you'd like to contribute to the development of the app, please fork the repository and submit a pull request.

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- An IDE like [Android Studio](https://developer.android.com/studio) (with the Flutter plugin) or [Visual Studio Code](https://code.visualstudio.com/) (with the Flutter extension).

### Getting Started

1. Clone the repository.
2. Run `flutter pub get` to install the dependencies.
3. Run `flutter run` to launch the app on a connected device or emulator.
